# Ep19 — Kiến trúc Mini-app (mỗi tính năng = 1 app riêng, gộp thành 1 app) — Plan

**Goal:** Monorepo `demo-miniapps/` hiện thực yêu cầu của người dùng: mỗi tính năng là một app độc lập (package riêng, CHẠY RIÊNG được) và gộp chung vào một app chủ. Kèm 1 video ep19 (~4-5 phút, "Super App tập 7") + thumbnail + SEO. KHÔNG đụng demo-superapp (nguồn sự thật của ep14–18).

## Kiến trúc demo-miniapps (npm workspaces)

```
demo-miniapps/
├── package.json                 # private, workspaces: ["packages/*", "apps/*"]
├── packages/
│   ├── mini-food/               # @vietsuper/mini-food — mini-app Đồ ăn
│   │   ├── package.json         # name, main: src/index.ts
│   │   └── src/index.ts + src/FoodScreen.tsx
│   ├── mini-wallet/             # @vietsuper/mini-wallet (WalletScreen, AsyncStorage)
│   └── mini-promo/              # @vietsuper/mini-promo (PromoScreen, fetch :3999)
└── apps/
    ├── vietsuper/               # app chủ Expo (expo-router 4 tab như cũ) — các tab chỉ
    │                            #   import screen từ @vietsuper/mini-* (2 dòng/tab)
    └── food-standalone/         # shell Expo blank CHẠY RIÊNG mini-food — bằng chứng
                                 #   "mỗi tính năng như 1 app riêng biệt"
```

- Screen components: cùng nội dung/nhìn như demo-superapp (Food menu 4 món + giỏ, Wallet AsyncStorage, Promo fetch 3999) nhưng sống trong package riêng, export tên *Screen.
- Peer deps (react, react-native, async-storage) khai peerDependencies trong mini packages; host/standalone cài dependency thật. Expo SDK 57 hỗ trợ monorepo tự động (Metro tự watch workspaces).
- Verify: npm install ở root; `expo export --platform ios` PASS cho CẢ vietsuper lẫn food-standalone; tsc clean.

**Ví von chủ đạo:** khu chung cư — mỗi mini-app một căn hộ có sổ đỏ riêng (package.json), app chủ là tòa nhà gắn biển; căn hộ tách ra ở riêng vẫn sống tốt (standalone shell).
