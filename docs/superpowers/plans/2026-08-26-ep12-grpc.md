# Ep12 — gRPC (Transporters bonus) — Plan

**Goal:** 1 video ep12 (~5 phút, dễ hiểu, khung như series B) + thumbnail + SEO, khép trọn sidebar Transporters. Định vị là "tập bonus" (vì ep11 đã chào kết) — title/intro nói rõ bonus theo yêu cầu người xem.

**Demo `demo-grpc/`** (gateway + users-service, KHÔNG cần Docker):
- Cả 2 app: `npm i @nestjs/microservices @grpc/grpc-js @grpc/proto-loader`; nest-cli.json thêm assets copy `**/*.proto`.
- File hợp đồng `src/users.proto` (cả 2 app giữ bản sao y hệt): package users; service UsersService { rpc FindAll (Empty) returns (UserList) }; message User {int32 id=1; string name=2}; UserList {repeated User users=1}.
- users-service: main.ts Transport.GRPC {package:'users', protoPath: join(__dirname,'users.proto'), url:'localhost:50051'} (tránh cổng 5000 vì macOS AirPlay); controller @GrpcMethod('UsersService','FindAll') trả {users:[Minh,Lan]}.
- gateway: ClientsModule GRPC cùng proto; controller OnModuleInit + client.getService('UsersService'); GET /users gọi findAll({}).
- Verify: curl gateway → {"users":[...]}. Cổng 3000 có thể bị Remotion Studio audiobook chiếm → test PORT=3002, video hiển thị 3000.

**Ví von:** REST/JSON = thư viết tay tự do (dài, dễ hiểu nhầm); gRPC = biểu mẫu in sẵn đánh số ô — hai bên cầm CÙNG một mẫu (file .proto = bản hợp đồng), điền số vào ô, gửi dạng điện tín nén (binary/HTTP2) → nhanh + không thể hiểu nhầm.
